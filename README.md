## Installation

To install these profiles, open a terminal and execute these commands:

```bash
git clone git@github.com:OrderTheCat/Apparmor-Profiles.git
```

```bash
mv ~/Apparmor-Profiles/apparmor.d /etc/apparmor.d
```
